===========================
N2 molecule on gold surface
===========================

simple demonstration example, inspired with ASE tutorial

https://share.google/aimode/bZuPslIjj9Og1vXzK

EMT Eads = -0.2706 eV
This is a noticeable overbinding artifact common to empirical models when simulating highly inert interactions
 on a flat closed-shell surface like Au(111).

MACE E_ads = -0.0448 eV
This result aligns beautifully with foundational physics.
On a pristine, flat Au(111)facet, the closed-shell electron configuration of the d-band barely overlaps 
with the sigma-orbitals of the N2 molecule. MACE accurately recognizes this interaction as a tenuous, weak physisorption state.
